# Orbit Quiz

Orbit Quiz is a small, single-page space exploration quiz. Answer 10 questions, follow your mission progress, learn a space fact after each answer, and review missed questions at the end.

The app is built as a single, dependency-free `index.html` file. It adapts to your system light or dark theme and respects reduced-motion preferences.

## Run locally

Open `index.html` directly in any modern browser. No server, build step, or dependencies are required.

## GitHub Pages

The site is deployed from the `main` branch with GitHub Actions. After Pages is enabled and the first deployment completes, it will be available at:
